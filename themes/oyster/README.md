# Oyster

Oyster is the local Hexo theme for this repository. It uses a minimal,
reading-first visual system inspired by Matrix67 while keeping the blog's own
content, routes, footer text, and homepage enhancements.

The theme is intentionally self-contained and uses the renderers already
declared by the root Hexo project.

It includes a centered fluid reading column, responsive H1/H2/H3 outline
indentation, Highlight.js code blocks with an adapted StackOverflow Light
palette and aligned line numbers, KaTeX legacy delimiter compatibility, and
extended Markdown footnotes. A build-time JSON index and lightweight browser
client provide local full-text search through the expanding header control.
